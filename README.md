# Lect'O'Note Matic 3000

Lecture de partitions à partir d'images : reconnaissance des notes (Audiveris), relecture et correction,
écoute avec réglage du tempo et transposition, puis réimpression d'une partition propre.

**Télécharger** : page [Releases](https://github.com/Ghomerr/music-reader/releases) — application de bureau sans
installation pour Windows, Mac (Apple Silicon et Intel) et Linux. Voir [v1/README.md](v1/README.md#application-de-bureau-windows-mac-linux)
pour le premier lancement.

- [v1/](v1/README.md) — l'application (serveur Node + interface, et application de bureau Electron)
- [PLAN.md](PLAN.md) — cadrage, décisions et état d'avancement
- [v0/](v0/README.md) — le banc de test de la reconnaissance qui a précédé la v1
